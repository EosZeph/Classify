# 归类采集工作台

一个可直接加载到 Chrome / Edge 的 Manifest V3 扩展，用于把网页中选中的文本按类别归档到本地项目工作台。

Zeph  
许可证：MIT  
当前版本：`1.8.0`

## 功能

- Popup 弹窗：启动或停止采集、新建项目、打开工作台、查看并切换最近项目。
- 新建项目：默认使用当前系统时间，可直接修改；可选择单组或多组模式，可勾选预设类别，也可添加并排序自定义类别。
- 项目顺序：项目按创建时间从旧到新、自上而下排列并显示连续序号；新项目追加在列表底部。
- 项目模式：单组项目保持现有逐条采集方式；多组项目允许多个数据组共用同一套类别，并可独立填写、采集和下载。
- 项目模板：可把当前项目的单组/多组模式、类别和类别顺序保存为模板，并在新建项目时直接套用。
- 项目锁定：项目可锁定，锁定后禁止删除项目、类别、分组、分组值和归档条目，解锁后可继续删除。
- 独立工作台：管理项目与类别，编辑、删除、排序、搜索和手动补录归档内容。
- 网页采集器：在网页中选中文本后点击“采集”，选择项目与类别即可自动归档。
- 网页侧边采集台：在网页右侧按类别直接预览内容；采集后自动展开并定位到对应类别。支持启停采集、切换项目、归档选区和删除内容，并通过“打开工作台下载”入口复用工作台的完整下载功能。删除操作会同步刷新侧边预览和工作台。悬浮标右上角可直接关闭，Popup 中可重新显示。
- 文本下载：支持选择项目和具体类别、内容，按“类别：内容”格式下载纯文本；选择全部时包含尚未采集内容的类别，输出类别名称和空内容。
- Word 下载：扩展直接生成标准 `.docx` 文件，类别名称加粗显示，并将类别与对应内容排版在同一段落。
- Excel 下载：生成标准 `.xlsx` 表格，分组作为行、类别作为列；空类别保留，摘要和结尾可自动合并整行。
- 分组独立文件：多组项目可把每个分组下载为独立 TXT/DOCX，也可打包为 ZIP，并可指定使用某个类别的值作为文件名。
- 本地持久化：使用 `chrome.storage.local`，不依赖服务器。
- 旧数据修复：升级时会按创建时间重新排列旧项目，并安全清理名称为“项目1”且没有任何内容的旧版空白项目。
- 清空项目：工作台左下角“清空项目”会删除全部项目，必须经过普通确认和输入“清空项目”两次确认；项目模板和采集开关会保留。

## 浏览器兼容性

本项目基于 Chrome Manifest V3 开发，主要支持桌面版 Chromium 内核浏览器：

| 浏览器 | 最低版本 | 推荐版本 | 支持状态 |
| --- | --- | --- | --- |
| Google Chrome | 109 | 最新稳定版 | 支持 |
| Microsoft Edge | 109 | 最新稳定版 | 支持 |
| 其他 Chromium 浏览器 | Chromium 109 | 最新稳定版 | 理论支持，建议自行验证 |

最低版本以 [manifest.json](manifest.json) 中的 `minimum_chrome_version` 为准。其他 Chromium 浏览器需要支持 Manifest V3、`chrome.storage`、`chrome.tabs` 和内容脚本功能。

当前版本面向桌面浏览器，不保证在 Firefox、Safari 以及不支持浏览器扩展的移动端 Chrome、Edge 中运行。

## 安装

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 将“归类采集”固定到浏览器工具栏。

项目不需要安装依赖，也不需要构建。

## 使用流程

1. 点击扩展图标，可先启动或停止采集，也可以直接新建项目。
2. 新建项目时选择“单组”或“多组”，默认名称是当前系统时间；勾选需要的预设类别，或输入、排序自定义类别。
3. 创建后扩展会自动打开该项目的工作台标签页。
4. 切换到任意普通网页，用鼠标选中文本。
5. 点击选区附近的“采集”，选择目标类别；也可以打开网页右侧“采集台”，直接点击类别归档当前选区，内容会自动预览在对应类别下。
6. 返回工作台即可编辑、搜索内容。
7. 多组项目可在工作台点击“新增分组”，每个分组按同一套类别填写数据；侧边采集台可切换当前采集组。
8. 多组项目可设置项目级“摘要”和“结尾”栏目，并分别调整类别顺序和分组顺序。
9. 工作台提供“下载文本”“下载 Doc”“Excel”三个入口，打开后选择项目和具体下载范围；多组项目还可选择摘要、结尾和分组独立文件。

## 下载格式

文本下载文件采用以下排版，每条内容单独一行，类别之间不插入空行：

```text
姓名：张三
姓名：李四
手机号：13800000000
备注：重点客户
```

不同类别之间不插入空行。下载对话框默认只勾选有内容的类别，用户可以进一步取消不需要的类别或单条内容。点击“全部选择（含空类别）”时，没有采集内容的类别会以 `类别：` 的格式输出。

多组项目下载时，每组单独一段：组内类别用中文逗号分隔，组末使用分号，最后一组使用句号。例如：

```text
姓名：张三，性别：男，手机号：13800000000；
姓名：李四，性别：女，手机号：13900000000。
```

下载格式支持：

- `TXT`：UTF-8 纯文本，每行一条 `类别：内容`。
- `DOCX`：可直接使用 Microsoft Word、WPS 等办公软件打开的 OpenXML 文档。多组合并下载时保持分组句式；选择分组独立下载时，每个类别单独一行，并沿用单组 DOCX 的字体和颜色。
- `XLSX`：分组作为行、类别作为列，空类别不会省略；摘要位于最上方，结尾位于最下方，并自动合并整行。

多组项目打开“每个分组生成独立文件”后，可选择使用分组名称或某个类别值作为文件名。独立 DOCX 中每个类别单独一行，并使用与单组 DOCX 一致的字体和类别颜色。独立文件可分别下载，也可打包为 ZIP。

下载窗口中的“文件格式预览”会根据当前项目、下载格式、摘要、结尾、分组选择和独立文件设置实时变化，不再显示固定示例。

## 权限说明

- `storage`：在本机保存项目和归档内容。
- `tabs`：创建并打开扩展工作台标签页。
- `<all_urls>`：在普通网页提供浮动采集器和侧边采集台。扩展不会主动上传网页内容。

## 使用边界

- 浏览器内部页面、扩展商店等受保护页面不允许内容脚本运行，因此不能在这些页面采集。
- 采集内容只保存在当前浏览器配置中。浏览器数据被清除或扩展被卸载时，数据也会被删除。
- 删除项目、类别或条目无法撤销，建议重要数据定期下载 TXT、DOCX 或 XLSX 备份。
- 使用者应确保采集和保存数据的行为已获得合法授权，并遵守目标网站条款和当地法律。
